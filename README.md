# MARKETVERSE — 투자자 메타버스 MVP

## 시작하기
Node.js 20 이상 필요.

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 다른 브라우저 탭에서도 접속하면 채팅, 접속자 수, 투표가 동기화됩니다.

## 구현됨
- Three.js 3D 투자 라운지, 키보드 이동 및 마우스 드래그 시점 변경
- 6개 자산 대형 전광판, 종목 상세 팝업
- Coinbase 공개 API를 이용한 BTC/ETH 현물 가격(15초 폴링, 호출 실패 시 연결 대기)
- WebSocket 기반 실시간 채팅, 접속자 수, 사용자 위치, 롱/숏 투표
- 모바일 반응형 UI(모바일 3D 이동 컨트롤은 차기 개발)

## 구현 전 / 주의
- 삼성전자, SK하이닉스, 코스피, 나스닥100 시세는 미연동. 가짜 가격을 표시하지 않음.
- 가격은 참고용이며 투자 및 주문용이 아님. 공개 API의 사용 조건과 호출 제한 확인 필요.
- 단일 Node 프로세스 메모리에 채팅/투표를 저장하므로 재시작하면 초기화됨.
- 현재는 개발용 프로토타입. 100~300명 동접 성능은 보장되지 않음. 출시 전 부하 테스트, 인증/모더레이션, 속도 제한, Redis pub/sub, 모니터링, HTTPS, 보안 검토 필요.
- Three.js CDN을 사용하므로 클라이언트 인터넷 연결 필요.
- 실제 서비스에는 주식/지수 시세 공급자의 라이선스와 재배포 권한 확인 필요.

## 3D 캐릭터 말풍선
- 채팅 전송 시 캐릭터 머리 위에 닉네임과 메시지가 표시됩니다.
- 모든 접속자에게 WebSocket으로 동시에 표시되며 5초 후 자동으로 사라집니다.
- 채팅 기록은 기존 오른쪽 채팅 패널에 유지됩니다.
- 업데이트 적용: 기존 서버에서 Ctrl+C로 중지 후 `npm.cmd start`로 재실행하고 브라우저를 새로고침하세요.

## ⚔ 1:1 ARENA (신규)
- 접속자에게 오목 대결 신청 → 상대 수락 → 15×15 오목 대결.
- 서버가 착수 순서/승패를 판정하고 관전자에게 동일한 판을 실시간 전송합니다.
- 대결 목록에서 누구나 관전할 수 있습니다. 대결자는 기권할 수 있습니다.
- 운영진 상품 설정: 서버 시작 전 `ARENA_ADMIN_KEY` 환경변수를 지정한 뒤, 웹사이트의 '운영진 상품 설정'에서 관리자 키를 입력합니다. 예: PowerShell에서 `$env:ARENA_ADMIN_KEY="본인만아는긴암호"` 후 `npm.cmd start`.
- 상품 정보 등록만 지원합니다. 쿠폰 자동 발송/당첨자 신원확인/대회 기간/부정행위 방지 기능은 미구현입니다. 상품 지급은 운영진이 수동으로 처리해야 합니다.
- MVP 제한: 경기·상품은 서버 재시작 시 초기화됩니다. 닉네임과 대결 권한은 브라우저 연결 기준으로, 로그인/인증/DB가 없습니다. 실서비스 전에 계정 인증, 영구 DB, 관리자 인증 강화, 게임 타임아웃 및 악용 방지 필요.
- 상업용 실시간 금융 데이터는 아직 미연동입니다. 라이선스 승인 전 실제 실시간 시세를 표시할 수 없습니다.


## 3D 경기장 버전
- 라운지 중앙에 원형 관전석과 15×15 오목판을 설치했습니다. 3D 보드에는 진행 중인 경기가 실시간 반영됩니다.
- 플레이어는 오른쪽 ARENA에서 대결 신청/수락, 경기 선택을 하고 3D 오목판을 클릭하여 착수할 수 있습니다.
- 아레나와 3D 라운지는 **하나의 WebSocket 연결**을 공유합니다. 이전 버전의 이중 소켓으로 인한 플레이어 ID 불일치를 수정했습니다.
- 기존 채팅, 말풍선, 6종목 전광판, 롱/숏 투표는 유지됩니다. 국내 주식/지수의 실제 실시간 데이터는 별도 상업 라이선스와 공급업체 연결이 필요합니다.
- 운영진 상품 등록은 `ARENA_ADMIN_KEY` 환경변수를 설정해야 하며, 상품 지급은 수동입니다.
- 현재 게임 상태는 서버 메모리에만 저장되므로 서버 재시작 시 초기화됩니다. 공개 운영 전 계정 인증, 부정행위 방지, 경기 기록 영속화, 관리자 권한 및 부하 테스트가 필요합니다.
